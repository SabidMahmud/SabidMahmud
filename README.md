## Research

### Interpretable Attention-Based Multiple Instance Learning for Cervical Cancer Detection

My undergraduate thesis investigated weakly supervised classification of full-resolution Pap-smear images using gated-attention multiple instance learning.

- Built binary triage and three-tier severity-grading pipelines.
- Used full-resolution patch extraction, background filtering, and attention-based aggregation.
- Generated native spatial-attention heatmaps to expose influential image regions.
- Co-curated PapSmear-BD from more than 300 slides into 2,253 expert-annotated field-of-view images.
- Contributed as second author to the dataset manuscript submitted to *Scientific Data*.

### Wildlife species classification

Benchmarked ResNet-50, EfficientNet-B0, and ViT-B/16 on severely imbalanced iWildCam imagery. Used sequence-aware splitting to reduce temporal and burst-level leakage, then studied the trade-off between overall performance and rare-species recall.

## How I approach projects

| Principle | What it means in practice |
|---|---|
| **Evidence before claims** | Metrics need a dataset, baseline, split, denominator, and reproducible method. |
| **Failure is part of the design** | Timeouts, invalid inputs, unavailable services, and insufficient evidence are normal system states. |
| **Explainability needs context** | A heatmap or model confidence is supporting evidence, not automatic proof. |
| **Research and production are different** | Experimental results must not be presented as clinical or production guarantees. |
| **Small systems can still be rigorous** | Tests, documentation, access control, and observability matter before massive scale. |
